# testing-reliability

Advanced plugin for testing and reliability workflows:

- Datadog dashboard authoring via MCP
- performance optimization specialist
- test execution specialist
- test writing specialist

## Datadog MCP

Default MCP endpoint is the **EU** site:

`https://mcp.datadoghq.eu/api/unstable/mcp-server/mcp`

LoyalGuru Datadog orgs use `app.datadoghq.eu`. Override only if you intentionally use another site.
