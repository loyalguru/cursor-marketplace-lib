# Productivity

Cursor plugin for structured planning interviews and decision stress-testing.

## What's Included

### Skills (`skills/`)

| Skill | Purpose |
|-------|---------|
| `grill-me` | Interviews the user one question at a time to stress-test a plan or design and resolve its decision branches. |

## Usage

Ask Cursor to “grill me” about a plan or design, or invoke `/grill-me`.
