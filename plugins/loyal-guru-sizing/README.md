# Loyal Guru Sizing

Cursor plugin for estimating engineering effort with Loyal Guru's T-Size scale and writing the result to Jira.

## What's Included

### Skills (`skills/`)

| Skill | Purpose |
|-------|---------|
| `loyal-guru-sizing` | Sizes tickets on the XXS→XL scale, calibrates with past work, writes **T-Size** (`customfield_11740`), drafts Internal notes for functional doubts, and opens cross-team product requests when needed. |

## Usage

Ask Cursor to size a ticket / estimate effort / put the T-Size, or invoke `/loyal-guru-sizing`.
