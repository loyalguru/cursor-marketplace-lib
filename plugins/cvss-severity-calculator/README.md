# CVSS Severity Calculator

Cursor plugin for calculating vulnerability severity consistently with CVSS v4.0 guidance.

## What's Included

### Skills (`.cursor/skills/`)

| Skill | Purpose |
|-------|---------|
| `cvss-severity-calculator` | Calculates CVSS v4.0 vectors, scores, and severity recommendations for security findings, Jira tickets, CVEs, and internal vulnerabilities. |

## Usage

Ask Cursor to calculate or review a vulnerability severity, or explicitly invoke `/cvss-severity-calculator`.
